# 算子机制与维护取舍

**机制证据已足以排除若干低价值优化方向，但尚未定位模型质量下降的唯一原因。** 实际诊断窗口内已细分writer的设备时间占全kernel不到1%，Graph内部未细分；单个相同元数据批次指向FP8 prefill attention的优化价值；1.5GiB BF16工作区方案数值正确但收益不足而停止扩大。真实短聊heldout K/V无饱和，现阶段不支持盲调全局scale。新BF16 Q decode在第46完成模型质量后仍未整体修复缺口，已停止该候选额外服务GPU扩展；它没有隔离Q因果。[第46补充](06_第46条BF16Q完整质量与停止决定.md)

## 1. KV存储、Q精度与MMA路径必须分开

| 组件 | 当前现代BF16 | 当前主FP8 | 新BF16 Q备选 |
| --- | --- | --- | --- |
| resident K/V | BF16 | FP8 E4M3，含scale | 仍为FP8 E4M3，含scale |
| prefill API Q | BF16，FA3 | BF16，FA2 | BF16，FA2 |
| decode | SM90 XQA BF16 | SM90 XQA，API虽接收BF16 Q，kernel内部转FP8 | 原生FA2，保留BF16 Q，KV片段转BF16参与BF16 MMA |
| 固定K/V scale | 不适用 | .125/.0625 | .125/.0625 |
| 完整BF16 KV影子 | 不适用 | 无 | 无 |
| 当前证据 | 模型/服务/质量 | 模型/服务/质量、有风险 | 算子/Graph128与第46模型质量已过完整性；质量未获接受，停止额外服务GPU矩阵 |

来源：[当前源码机制](../operations/20261026T075846Z/PRODUCTION_SOURCE_FINDINGS.md)、[XQA完整质量配置](../experiments/production-xqa-quality-full1719-20261026/REPORT.md)、[新备选独立审计](../operations/20261026T075846Z/bf16q_decode_operator_independent_audit_a1.json)，`graph128.backend`、`installed_sources_sha256`。API张量dtype不能替代内核内部数值路径；resident FP8也不意味着整个attention都用FP8 MMA。

H800/SM90上现装FA3 dtype支持不接受BF16-Q/FP8-KV组合；不能只改planner字符串绕过C++保护，或者拿FA3 FP8-Q的结果当BF16-Q认证。先前FA3全路径、FA2+XQA、当前BF16 Q备选都是不同部署配置；不把其差异合成纯KV dtype因果。[上游/现装源码复核](../operations/20261026T075846Z/UPSTREAM_BACKEND_REVIEW.md)

本模型本来已有40Q/8KV heads的GQA，权重/MLP仍BF16；压缩KV几乎一半不会令完整模型计算时间减半。prefill、decode、writer、CPU提交、Graph、队列和更大驻留之间的相互作用，解释了不同workload下“容量相同收益、时延不同方向”的可能性；这是一组机制候选，未由现有统计完成因果分解。

## 2. 从源码能够确认与不能确认的开销

BF16与FP8路径都对K/V做连续化/materialization，不能把全部`contiguous()`成本都算给量化。FP8额外缩放、裁剪、FP8转换和scale写入确实存在；固定scale的Triton constexpr分支可能让编译器消掉中间amax reduction，源码表面先写amax再覆盖不能证明GPU仍执行了冗余reduction。具体占比要看设备轨迹。[源码审计](../operations/20261026T075846Z/PRODUCTION_SOURCE_FINDINGS.md)

resident scale数组属于存储/复制契约，但FlashInfer读路径消费固定scalar；scale驻留字节不是attention实际HBM读量。XQA每层直接读resident FP8 pages，无全量BF16 shadow。旧校准器只记每层第一次prefill/decode，不能冒充全workload跨请求校准。NVML memory-controller activity只表示活动比例，现无HBM bytes/s或完整硬件流量证据。

## 4. BF16 prefill工作区：算子正确，但成本screen停止扩大
